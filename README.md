# 📈 Retail Sales Analytics & Forecasting Dashboard

## 📌 Project Overview

The **Retail Sales Analytics & Forecasting Dashboard** is an end-to-end data analytics project designed to analyze retail transaction data, discover meaningful business insights, understand customer and product behavior, and forecast future sales.

The project uses **Python, Pandas, SQL, and Power BI/Streamlit** to transform raw retail transaction data into useful analytical insights and interactive visualizations.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze historical retail sales data.
- Clean and preprocess transaction-level data.
- Identify top-selling products.
- Analyze revenue and sales trends.
- Understand customer purchasing behavior.
- Analyze sales performance by country.
- Identify return/cancellation patterns.
- Perform customer segmentation using RFM analysis.
- Forecast future sales using time-series forecasting.
- Build an interactive dashboard for business decision-making.

---

## 🗂️ Dataset

This project uses the **UCI Online Retail Dataset**.

The dataset contains transaction-level information from a UK-based online retail business.

### Important Features

| Column | Description |
|---|---|
| `InvoiceNo` | Unique invoice/transaction number |
| `StockCode` | Product/item code |
| `Description` | Product description |
| `Quantity` | Number of items purchased |
| `InvoiceDate` | Date and time of transaction |
| `UnitPrice` | Price per item |
| `CustomerID` | Unique customer identifier |
| `Country` | Customer's country |
